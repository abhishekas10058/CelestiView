CELESTIVIEW IS A STUDENT-BUILT ASTRONOMY PLATFORM DESIGNED TO SHOWCASE NASA’S ASTRONOMY PICTURE OF THE DAY IN A MODERN, IMMERSIVE INTERFACE.

The goal of CelestiView is to make space exploration visually engaging by presenting daily astronomical images and videos provided by NASA’s APOD service.

This project is built using HTML, CSS, JavaScript, and public NASA APIs. It focuses on clean UI design, smooth animations, and educational value.

CelestiView is an academic project and is not affiliated with NASA.
